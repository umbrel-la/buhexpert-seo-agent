# БухЭксперт: SEO-статья с AI-помощником

Интеграция логики AI-помощника из `buhexpert-ai-mvp` в основной прототип БухЭксперта. Помощник работает и на главной, и внутри SEO-статьи `/articles/os-v-1c-8-3`: поддерживает историю диалога, preview до регистрации, demo-авторизацию, уточняющие вопросы и серверную защиту API-ключа. Вопросы из статьи получают её полный текст из серверного белого списка; системная инструкция, статья, дополнительные материалы и реплики диалога разделены XML-разметкой.

## Технологии

Next.js 16 App Router, React, TypeScript, обычный CSS, серверный OpenAI-compatible API. База данных и UI-библиотеки не требуются.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Production-проверка:

```bash
npm run build
npm start
```

## AI и переменные окружения

Скопируйте `.env.example` в `.env.local` и при необходимости укажите:

```env
AI_API_KEY=
AI_BASE_URL=
AI_MODEL=
AUTH_MODE=demo
BUHEXPERT_SESSION_COOKIE=
NEXT_PUBLIC_YM_COUNTER_ID=
```

`AI_API_KEY` доступен только серверному коду. Пустой `AI_BASE_URL` использует OpenAI API. Демонстрационный режим (`AUTH_MODE=demo`) показывает preview и раскрывает уже сформированный ответ после тестовой формы email → код; письмо не отправляется, аккаунт не создаётся. История чата и demo-вход существуют только до обновления страницы.

## Деплой на Vercel

1. Загрузите репозиторий на GitHub.
2. Импортируйте его в Vercel как Next.js-проект.
3. При необходимости добавьте перечисленные переменные окружения.
4. Выполните Deploy. Без `AI_API_KEY` интерфейс продолжит работать на локальном демонстрационном ответе.

## Ограничения MVP

- Материалы и ответы демонстрационные и не являются бухгалтерской консультацией.
- Поиск основан на совпадениях текста, без векторной базы.
- Числового лимита запросов в H01 нет. Защита от двойной генерации действует в памяти текущего процесса и имеет TTL; для production нужен общий Redis/БД-кэш и rate limit.
- При `AUTH_MODE=real` полный ответ не выдаётся, пока `lib/auth.ts` не подключён к настоящему провайдеру и не проверяет серверную сессию.
- Форма консультации валидируется, но ничего не отправляет.
- Платежи и личный кабинет не подключены.

Исходный визуальный прототип сохранен в `reference/buhexpert-ai-prototype.html`.
